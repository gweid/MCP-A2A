# MCP & A2A

MCP 协议旨在连接大模型与外部工具，解决模型与现实世界的割裂问题，它提供标准化接口，简化大模型对工具的调用过程，类似 USB 标准

A to A 协议关注智能体之间的交互，让不同的智能体（Agent）能够无障碍地沟通和协作，解决 Agent 与 Agent 之间如何发现、通信和协作
